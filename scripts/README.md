# Contributing

Thanks for helping improve this project.

## Workflow

1. Fork the repository
2. Create a branch for your change
3. Keep changes focused and clear
4. Validate shell scripts with `bash tests/validate.sh`
5. Open a pull request with a clear summary

## Notes

- This project targets Termux and Frida workflows.
- Be careful with game-related tooling and follow local laws and policies.
- Prefer small, tested improvements.
